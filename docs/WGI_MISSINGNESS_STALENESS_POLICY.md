# WGI missingness and stale-observation policy candidate

Status: **proposed research policy, not provider guidance or production approval**.
Stacked on draft #14 at `520dc87d67a9998a5150539ebd4aea86c711d8a9`.
Assessment date: 26 October 2026. No network access is required or performed.

## Decision contract

The unchanged baseline helper `latest_available_by_country` selects the latest
non-null observation independently for each indicator up to a target year and
retains its observation-year column. This milestone introduces a separate gate
over the frozen #14 coverage evidence. It does not alter that helper, supply
numeric inputs to scoring, or change the production pipeline.

1. Require the four scored dimensions **PV, RL, CC and GE** from **one common
   observation year**. Each dimension must have all six aggregate fields
   verified by #14: EST, SE, SR, SC, SC_LB and SC_UB. This deliberately conservative
   bundle is a project requirement, not a claim that the baseline uses all six.
2. The proposed default `STRICT_SAME_YEAR` allows age zero relative to the target
   year. A separate `ONE_YEAR_LAG_SENSITIVITY` permits age zero or one, labels
   older selections explicitly, and is never enabled in the baseline.
3. Choose the most recent complete common bundle at or before the target year.
   If it exceeds the allowed age, withhold selection while retaining its year
   and age as diagnostic evidence. If none exists, withhold as no common bundle.
4. No cross-year dimension splicing, imputation, zero substitution, averaging,
   uncertainty inflation, or scoring-weight redistribution. Future observations
   cannot repair historical target-year gaps. One-dimensional coverage is not
   sufficient for a country-level selection.
5. VA and RQ gaps remain informational for this gate; they are visible but do
   not block the four scored dimensions. RQ is not added to model scoring.
6. Every output has `production_use_authorized=False`. A research-eligible result
   means only that this coverage/age rule passes, not that the country is safe,
   the data are accurate, uncertainty is calibrated, or a risk score may be issued.

The age cutoffs are explicit analyst assumptions in
[the policy configuration](provenance/wgi_observation_policy.json). They are
not empirically calibrated. An annual provider release can legitimately lag
its observation year; consequently strict same-year selection can withhold
otherwise useful research data. The one-year variant makes that tradeoff
reviewable without silently treating a 2025 observation as a 2026 observation.

## Temporal interpretation

Three dates remain distinct: target year, selected observation year and evidence
assessment date. `candidate_age_years` is target year minus candidate observation
year. `candidate_age_at_assessment_years` is assessment year minus that year.
These are integer calendar-year differences, not exact elapsed days.

A 2024 observation passes a target-2024 age-zero test while being two calendar
years old at the 2026 assessment. It is not described as fresh evidence for a
current 2026 decision. A target outside the retained snapshot, such as 2026,
is explicitly marked `target_year_in_snapshot=False`; no claim is made about
unqueried later provider releases.

The retained 2026 release revises history. Evaluating target 2024 using it is a
**retrospective coverage exercise**, not a point-in-time backtest. Evidence
retrieved after a requested assessment date is rejected. Every result retains
`point_in_time_backtest_validated=False`; historical point-in-time eligibility
would require a separately verified contemporary vintage and availability log.
Changing an observation-year label cannot satisfy that requirement.

## Frozen evidence and scope

The input is the complete 6,480-row country-year coverage grid generated by the
[WGI workbook/API parity milestone](WGI_WORKBOOK_API_PARITY.md). Its byte hash is
checked against #14's receipt. The receipt itself is pinned by a canonical JSON
SHA-256 in the policy configuration, avoiding line-ending-only discrepancies.
Only the specifically retained parity-success snapshot is accepted. New or
changed snapshots need a separately reviewed evidence/configuration update.

The loader rejects mismatched hashes, parity exceptions, incompatible source
identity, future evidence dates, unknown dimensions, duplicate/missing
country-years and inconsistent bundle counts. For this snapshot, six-field
bundles are all-or-none; that assumption is checked, not generalized to future
datasets. Coverage retains absent/null distinctions upstream; this gate requires
a complete matched bundle regardless of which unavailable state caused its loss.

The universe remains 216 provider economies, including historical entities and
territories. It is not the production model's final merged cohort. No provider
values, source-mean columns, new workbook data, ACLED records, personal details
or itineraries enter this layer. ACLED remains documentation-only and all earlier
baselines, receipts, synthetic fixtures and published outputs remain unchanged.

## Reproduction and tests

Use the coverage grid already retained locally from #14. If unavailable, follow
#14's documented offline replay using the original downloads; the grid must
match the pinned hash. A fresh live acquisition is not a substitute for that
frozen input and is not performed by this milestone.

```bash
python -m pytest -q tests/test_wgi_observation_policy.py
python -m pytest -q
python -m src.wgi_observation_policy --coverage-csv data/raw/wgi_parity_publish_20261026/country_year_coverage.csv --output-dir data/raw/wgi_policy_NEW
```

The output directory must be new. Tests use fictional metadata to exercise exact
and boundary ages, each required dimension, informational gaps, no common year,
future-observation exclusion, retrospective vintage limits, malformed evidence,
hash tampering, deterministic offline replay and refusal to overwrite.
Existing CI includes these tests and earlier synthetic demonstrations; it needs
no credentials or real-source downloads. This layer adds no dependencies.

Before any production adoption: approve the target-year/lag policy, validate a
numeric adapter with units and uncertainty preserved, reconcile the actual model
cohort, specify unavailable-output behavior throughout the scoring chain, and
independently validate the methodology. Historical backtesting and ACLED access
remain separate gates. No PR is merged, main is untouched, and issues #9/#11
are not closed by this milestone.
